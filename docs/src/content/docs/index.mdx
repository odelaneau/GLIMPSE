GLIMPSE2 builds on the [GLIMPSE model](https://www.nature.com/articles/s41588-020-00756-0) and puts the emphasis on rare variants. It takes a reference panel and low-coverage BAM/CRAM files, or genotype likelihoods, and returns phased and imputed genotypes. A chromosome is cut into chunks that are processed independently, and `phase`, the only expensive step, runs on all of them in parallel.

## How it works

```bash
# 1. Cut the chromosome into imputation chunks
GLIMPSE2_chunk --input panel.sites.vcf.gz --region chr22 \
  --map chr22.b38.gmap.gz --output chunks.txt

# 2. Convert the reference panel to the binary format, once per chunk.
#    This is done once per panel, and works for any sample.
GLIMPSE2_split_reference --reference panel.bcf --map chr22.b38.gmap.gz \
  --input-region $IRG --output-region $ORG --output panel/chr22

# 3. Impute and phase, once per chunk, in parallel
GLIMPSE2_phase --bam-file sample.bam \
  --reference panel/chr22_${CHR}_${START}_${END}.bin \
  --output imputed/chunk.bcf

# 4. Ligate the chunks into a chromosome
GLIMPSE2_ligate --input chunks.list.txt --output chr22.imputed.bcf
```

The [tutorial](tutorial/getting-started/) goes through each step with a 1x NA12878 sample and the 1000 Genomes reference panel.

## What's new in 2.1

- **Faster, with less memory.** In our benchmarks `phase` is about 1.5 to 5 times faster and uses 2 to 5 times less memory than 2.0.1, depending on the panel and the input.
- **ARM64.** GLIMPSE2 now builds and runs natively on Linux aarch64 and on Apple silicon.
- **`inspect`**, a new tool to summarise a binary reference panel.
- **Checkpoints** in `phase`, so a preempted cloud job can resume.
- **Bug fixes.** Several of them change the output, so read [what changed](changelog/#changes-to-output) before comparing against results from 2.0.1.

The [changelog](changelog/) has the full list of changes.

## GLIMPSE1 or GLIMPSE2?

For most applications, use GLIMPSE2. It is faster, handles much larger reference panels, and is the version we maintain.

[GLIMPSE1](glimpse1/index.html) has not been updated for a while, and we would not recommend it in general. It is only worth a look for its joint model, which helps with many samples at higher coverage (above 0.5x) and small reference panels, and which GLIMPSE2 does not have: GLIMPSE2 imputes from a reference panel only.

## Related software

GLIMPSE is part of a family of methods from the same group.

- [SHAPEIT5](https://odelaneau.github.io/shapeit5/) phases large sequencing cohorts, with a focus on rare variants. Use it to build the phased reference panel that GLIMPSE2 imputes from.
- [IMPUTE5](https://jmarchini.org/software/) imputes SNP array data against large reference panels.
